#Circular Garden

#Desc
##This program helps calculate the Circumference, Square root and the Area rounded up and down.

#How to Run
##Enter the radius of the garden in meters.

#Input needed
##Radius of the garden in meters

#Sample output
##Input:5
 Area: 78.54
 Circumference: 31.42
 Square root: 8.86
 Area rounded up: 78
 Area rounded down: 79
